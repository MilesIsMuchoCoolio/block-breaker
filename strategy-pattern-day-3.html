Day 3 • Strategy Pattern

Trace the Swap

Build flexible behavior by swapping strategies instead of rewriting the game logic.

Goal

Learn how the strategy pattern lets an object choose a different behavior at runtime without changing its core rules.

The idea

What changes?

Instead of hard-coding one movement rule into the paddle, the game keeps a reference to a current strategy. The paddle says, “Use my current strategy,” and that strategy decides how to move. 

const paddle = {
  moveStrategy: moveLeftRight,
  update() {
    this.moveStrategy(this);
  }
};

Trace the swap

When the player changes the way the paddle should act, the game swaps the strategy instead of rewriting the whole paddle class.

How the behavior changes
Situation Current Strategy Result
Basic play Move normally Paddle follows arrow keys with steady movement.
Boosted mode Speed-up strategy The same paddle responds faster for a short time.
Special effect Heat-seeking or scatter strategy The behavior shifts without changing the rest of the game loop.

Why this is useful

The strategy pattern helps the game keep one object, like the paddle, while changing how it acts based on power-ups, level changes, or player input.

Key rule

A class should depend on an interface or shared behavior, not on one exact movement rule. That way, the strategy can change while the system keeps working.
