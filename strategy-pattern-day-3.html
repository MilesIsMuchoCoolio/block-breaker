Same loop. Different behavior.

Today's goal

By the end of class, I can trace how a brick uses its strategy each frame, and say what changes when I swap slide for stayStill.

Read only · Thursday you'll add this loop to update()

The loop in update()

It asks every brick to run its own strategy:

for (const brick of bricks) {
  brick.move(brick);   // runs slide OR stayStill
}

In the brick factory, each brick gets a strategy:

move: slide,      speed: 2,   startX: x,   // the row that slides
move: stayStill,  speed: 0,   startX: x,   // every other row

The key rule

The loop never changes. To change how a brick behaves, swap one word in the brick factory: slide or stayStill.
